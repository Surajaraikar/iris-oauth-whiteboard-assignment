# Reviewer demo

1. Configure Google OAuth client and Search Console API using `.env.example`; consent-screen users may need to be explicitly listed while the app is in testing.
2. Start the compose stack and connect an account.
3. Discover properties and inspect a URL beneath an accessible property. Explain that inspection describes the indexed version, not live indexability.
4. For notifications, use only an eligible JobPosting or BroadcastEvent-in-VideoObject page after Indexing API project approval. The accepted message says notification only; indexing is not guaranteed.
5. Disconnect and verify local credentials disappear. If remote revocation cannot be confirmed, revoke the app from the user's Google Account.

Without credentials, the dashboard can still be reviewed, but Google-backed screens correctly show the unconfigured/empty state.
